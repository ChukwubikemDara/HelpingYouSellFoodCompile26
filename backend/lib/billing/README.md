BillingAdapter is a v0.6 integration boundary. Pickup commits one durable usage outbox record in the same transaction. A future dispatcher sends events to the actual provider using reservation_id for idempotency, then records delivery. Usage is not currently delivered; no billing links are fabricated. Plan gating defaults off in publishCommand and may be enabled explicitly. Actual fee rate remains unspecified by v0.6 and must come from configured pricing, not its illustrative Summary example.
