Customer signup/signin and bearer sessions are implemented in accounts.ts. Native mobile tokens use SecureStore. Merchant sessions use an httpOnly SameSite=Lax cookie, expire after 24 hours and derive ownership from the server account. Customer sessions are non-expiring per today's contract and can be revoked through the additive signout route. Passwords use salted scrypt; public Customer projection strips hashes. HTTP writes with merchant cookies require an allowed Origin. X-Merchant-Id and X-Device-Id are not authorization mechanisms.
